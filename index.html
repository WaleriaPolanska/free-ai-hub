Free AI Hub

"No card needed" hides services that ask for a bank card at signup, even when they are free.

⚠ Before you start - "free" has two layers

1. The tool (patch, skill, extension) - free and open source.
2. The AI model behind it - this is what can cost money. A free tool connected to a paid API (Claude, GPT, Gemini) is billed by that provider per token.

Fully free = free tool + a model from AI → Free (Groq, OpenCode, OrcaRouter, MoonMath...) or a local model via Ollama. Every patch and skill card says which AIs make it free and which make it paid.

AI offer types

  • Free forever - permanent free tier or daily limit
  • Credits / trial - one-time or monthly balance
  • Nearly free - paid, but pennies

How to use this site

  1. AI - hover the tab to pick Free or Paid. Bookmarks split it into Free forever, Credits / trial and Install yourself (open models you download, run and fine-tune). Tick "no card" to see services that need nothing
  2. Skills - hover the tab to pick Free or Paid, then open a colored bookmark on the left to flip to that folder
  3. Patches - bookmarks on the left split tools into folders: routers, CLI agents, IDE extensions, local models, chat UIs, MCP servers and more
  4. Every GitHub card shows its ★ stars and last update, refreshed automatically
  5. Cloud & tools - non-AI deals: cloud credits, VPS, proxies, SMS numbers, search APIs for agents
