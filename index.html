Free AI Hub

⚠ Before you start - "free" has two layers

1. The tool (patch, skill, extension) - free and open source.
2. The AI model behind it - this is what can cost money. A free tool connected to a paid API (Claude, GPT, Gemini) is billed by that provider per token.

Fully free = free tool + a model from AI → Free (Groq, OpenCode, OrcaRouter, MoonMath...) or a local model via Ollama. Every patch card has a "When is it free?" line with the exact details.

How to use this site

  1. AI - hover the tab to pick Free or Paid, tick "no card" to see services that need nothing
  2. Skills - hover the tab to pick Free or Paid, then pick by purpose color
  3. Patches - plug free models into your tools (claude-code-router, LiteLLM)
  4. Cloud & tools - non-AI deals: cloud credits, VPS, proxies, SMS numbers, search APIs for agents
